  достижимых из локальных refs и reflog до этого коммита.
- Публичные ветки и теги сверены через GitHub API: только main, тегов нет.
  Удалённый main совпал с проверенным локальным origin/main; fetch также выполнен.
- Искались точные значения локальных ключей и паролей из серверного .env и
  frontend/.env.local без вывода этих значений; дополнительно проверены
  форматы OpenAI/LLM-провайдер, Tavily, GitHub, AWS access key ID и приватных ключей.
- Отдельно проверено отсутствие настоящих .env в Git-истории и пустые поля
  ключей в .env.example и frontend/.env.example.
- Результат: совпадений не обнаружено. README и новые отчёты содержат только
  названия переменных и пустые поля. Локальный служебный отчёт исключён из Git.

Это поиск по доступным версиям файлов и известным признакам, а не доказательство
отсутствия любого возможного секрета. Не проверялись чужие форки, недоступные/удалённые
refs, ранее скачанные копии, GitHub Actions logs и настройки account-level secret scanning.
При обнаружении утечки ключ сначала отзывают у провайдера: удаления файла из новой
версии недостаточно, поскольку старые коммиты сохраняются.
